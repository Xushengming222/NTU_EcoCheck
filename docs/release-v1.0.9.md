# 1.0.9 — NTU 电费查询与缴费增强版

基于 **[UWPBOOM/NTU_EcoCheck](https://github.com/UWPBOOM/NTU_EcoCheck)** 修改，参考提交 `d88044b696267f7f5d19c600ca237c1135776d01`，保留原作者署名。增强版由 **Xushengming222** 维护，按 **Apache License 2.0** 分发，非学校官方应用。仅适配南通大学统一身份认证及宿舍缴费系统。

## 相比参考项目的改动

- 保留原版查询界面、五步进度、电量结果和历史记录。
- 新增“一键缴费”：先显示网页版缴费及相册扫码说明，确认后打开学校平台并填写宿舍；金额与付款由用户确认。
- 新增滑块、验证码和登录错误提示，限制自动登录提交，遇到验证时停止自动提交。
- 适配手机上的金额输入、支付方式选择、蓝色确认按钮和二维码页面，支持切回原网页。
- 在本机识别微信、支付宝支付二维码，支持保存至相册后到对应平台扫一扫付款；学校提供可直接打开的原链接时使用其原链接。
- 新增原创“书页、闪电、电流环”图标；关于页面列明原作者、增强版维护者、修改范围，并可离线查看许可与署名。
- 附带 LICENSE、NOTICE、修改说明及第三方许可。完整对照见 [CHANGES.md](https://github.com/Xushengming222/NTU_EcoCheck/blob/master/CHANGES.md)。

## 安装与使用

下载附件 **NTU_EcoCheck-v1.0.9.apk** 安装，最低 Android 8.0。应用名称为 **NTU电费查询**，版本号为 **1.0.9**，不附加构建后缀。包名 `com.ntu.electricity.payment`，可覆盖此前同签名的增强版并保留配置，也可与原版同时安装。

支付时先核对宿舍与金额，将付款码保存至相册后，在对应的微信或支付宝“扫一扫”中选择图片付款。二维码有效期和支付结果以学校官方页面及订单状态为准。

## 验证范围

- APK 构建、Android lint、45 项网页检查和 12 项 JVM 单元检查通过。
- 金额输入与支付确认控件已在 320、360、390、430px 的离线页面模型中检查；提供的微信、支付宝二维码截图已用应用解码器离线识别。
- 开发环境未使用真实学校账号创建或支付订单，Android 真机上的完整登录、相册扫码和支付应用唤起仍需使用时核验。

附件包含 APK、对应源码及 SHA-256 校验文件；源码和许可也可在仓库查看。
