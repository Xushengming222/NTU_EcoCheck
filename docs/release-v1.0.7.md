# NTU 电费查询与缴费增强版 1.0.7

1.0.7 是本地图标候选版，没有创建公开 Release。当前发行许可与发布内容已经整理到 [1.0.9 发布说明](release-v1.0.9.md)、[LICENSE](../LICENSE) 和 [NOTICE](../NOTICE)。下列功能说明仅描述当时的候选构建。

本版本面向南通大学学生，保留原版的电量查询弹窗、五步进度、结果与历史记录，增加学校网页版缴费入口和宿舍信息自动填写。它是学生个人增强版。

## 功能与调整

- 新增原创校园用电图标，结合校蓝、书页和闪电；未复制学校官方校徽。
- 一键缴费前先显示网页版平台及相册扫码的使用说明，确认后才进入。
- 滑块或登录错误出现时改由用户处理；同一账号的自动提交频率受到保护。
- 适配电费金额输入、后续支付方式选择、确认按钮和二维码页面。
- 在本机读取微信、支付宝支付码；扫码订单支持保存到相册后在对应平台扫描。
- 关于页面展示实际版本，授权入口指向原仓库说明。

## 安装与验证范围

最低 Android 8.0。当前候选安装包继续使用 `com.ntu.electricity.payment` 和原测试签名，可覆盖上一测试版并保留其配置。

已有离线表单与布局测试、JVM 单元测试及构建检查；未使用真实学校账号创建或支付订单，也未在开发机连接的 Android 手机上验收学校登录、二维码读取和支付应用唤起。付款时应核对官方页面中的宿舍、金额和订单结果。
